# JavaScript Memory Card Game

A vanilla JavaScript, CSS, and HTML memory card matching game backed by Supabase.

## How to Run Locally
Because this project uses JavaScript ES Modules (`type="module"`), you cannot simply double-click `index.html` to open it in your browser. You must serve it over a local HTTP server.

**Using VS Code:**
1. Install the "Live Server" extension by Ritwick Dey.
2. Open this project folder in VS Code.
3. Click "Go Live" in the bottom right corner of the status bar.
4. The game will open in your browser at `http://127.0.0.1:5500`.
