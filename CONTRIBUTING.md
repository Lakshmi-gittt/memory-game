# Team Workflow (Fork and Pull Request)

1. **Fork the Repository:** Click the "Fork" button at the top right of the main GitHub repository to create a copy in your own GitHub account.
2. **Clone your Fork:** `git clone https://github.com/YOUR-USERNAME/memory-card-game.git`
3. **Create a Branch for your feature:** `git checkout -b feature-css` (or `feature-game-engine`, etc.)
4. **Write your code:** Follow the strict instructions provided in your assigned file's comments.
5. **Commit and Push:**
   - `git add .`
   - `git commit -m "Completed [my feature]"`
   - `git push origin feature-css`
6. **Create a Pull Request (PR):** Go to the main repository on GitHub and click "Compare & pull request". The Lead will review and merge your code.
